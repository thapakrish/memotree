# Contributing to MemoTree

MemoTree is open source under the MIT License. Issues, bug reports, design feedback, and pull requests are welcome.

## Development

```bash
npm install
npm run dev
```

Before opening a pull request, run:

```bash
npm run build
npm run lint
```

## Contribution License

By submitting a pull request, you agree that your contribution is provided under the same MIT License that governs this repository.

Please do not include API keys, credentials, private conversations, or other secrets in issues, commits, screenshots, or test fixtures.
